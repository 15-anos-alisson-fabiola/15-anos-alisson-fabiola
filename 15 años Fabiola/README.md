## 🚀 Pasos para Subir a GitHub Pages

### 1. Cambiar URLs en `index.html`
Abre el archivo y busca `TU-USUARIO` y `TU-REPO` (líneas 13-14):

```html
<!-- Cambiar ESTO:
<meta property="og:image" content="https://TU-USUARIO.github.io/TU-REPO/fotos/Foto_Portada.jpg">
<meta property="og:url" content="https://TU-USUARIO.github.io/TU-REPO/">

POR ESTO (con tus datos reales):
<meta property="og:image" content="https://tu-usuario.github.io/tu-repo/fotos/Foto_Portada.jpg">
<meta property="og:url" content="https://tu-usuario.github.io/tu-repo/">
```

**Número de WhatsApp ya está configurado: 78429020**

### 2. Crear repositorio en GitHub

```bash
cd "15 años Fabiola"

git init
git add .
git commit -m "Invitación 15 años Alisson Fabiola"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPO.git
git push -u origin main
```

### 3. Habilitar GitHub Pages

1. Ir a: Configuración (Settings)
2. Bajar a "Pages"
3. En "Source" seleccionar "main" branch
4. Hacer clic en "Save"
5. Esperar 2-3 minutos
6. La URL será: `https://tu-usuario.github.io/tu-repo/`

### 4. Compartir las Invitaciones

Cada invitado recibe un enlace único. Del archivo Excel "Invitados.xlsx", copia la URL base + enlace:

**Ejemplo:**
```
https://tu-usuario.github.io/tu-repo/?name=alisson_fabiola&row=1
```

